# To-Do App (scaffold)

A starter Flutter project with the basic structure ready for further development.

How to use:

1. Make sure you have the Flutter SDK installed.
2. Open the project folder in your terminal.
3. Run `flutter pub get` to install the dependencies.
4. Run `flutter run` to launch the app on a device or emulator.

Note: This repository includes only the foundation (UI and placeholders).
